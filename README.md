# Full Stack Real-Time Chat App

A modern MERN stack chat application with real-time messaging using Socket.io.

## 🚀 Features
- User authentication (JWT)
- Real-time messaging
- One-to-one & group chat
- Typing indicators
- Online/offline status
- Responsive UI

## 🛠 Tech Stack
- MongoDB
- Express.js
- React.js (Vite)
- Node.js
- Socket.io
